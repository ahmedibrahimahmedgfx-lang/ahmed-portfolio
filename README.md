# Ahmed Ibrahim / Selected Recordings

Portfolio website for **Ahmed Ibrahim, Strategic Brand Designer / Art Director**.
A digital visual mixtape: the portfolio's editorial system (Albertus display caps, expanded grotesk metadata, near-black ground, a single acid accent) rebuilt as a native web experience with a recurring *tape line*, a contextual cursor, pointer-driven previews, connected page transitions and real motion from the original films.

Static site. **Astro + TypeScript + GSAP/ScrollTrigger.** No backend.

---

## 1. Install

Requirements: Node 20+ (22 recommended), npm.

```bash
npm install
```

## 2. Local development

```bash
npm run dev        # http://localhost:4321
```

## 3. Production build

```bash
npm run build      # type-checks, then builds to dist/
npm run preview    # serves dist/ locally
```

`npm run build:fast` skips the type check.

## 4. Deploy to Cloudflare Pages (free)

1. Push this folder to a new GitHub repository (the `public/media` folder is part of the site and must be committed, about 66 MB).
2. Cloudflare dashboard → **Workers & Pages → Create → Pages → Connect to Git** → choose the repository.
3. Build settings:
   - Framework preset: **Astro**
   - Build command: `npm run build`
   - Build output directory: `dist`
   - Environment variable: `NODE_VERSION = 22`
   - Environment variable: `SITE_URL = https://your-domain` (used for canonical URLs, Open Graph and the sitemap; defaults to `https://ahmed-ibrahim.pages.dev`)
4. Deploy. Every push to the main branch redeploys.
5. When the final domain is known, also update the `Sitemap:` line in `public/robots.txt`.

No file is larger than 25 MB, so everything fits Cloudflare Pages limits.

```

  data/site.ts         contact, tracklist, profile, logos, typography works, films
  data/media.json      generated by the media script (sizes, placeholders)
  components/          page sections (Opening, Profile, ProjectIndex, Logos, ArtDirection, Typography, VisualRD, Closing…)
  layouts/Base.astro   head/SEO, persistent HUD, tape bar, cursor, preview, film player, tracklist overlay
  pages/index.astro    the mixtape
  pages/work/[slug].astro  case-study template
  scripts/             cursor, preview, tape bar, film player, navigation, scroll motion
  styles/global.css    design tokens and every component style
public/
  fonts/               WOFF2 (Albertus Medium subset, Archivo, IBM Plex Mono, Alexandria Arabic)
  media/img/           AVIF + WebP at 720 / 1280 / 2048 px
  media/motion/        loop previews (MP4 + WebM, muted), full films (MP4), posters
scripts/media/
  images.json          every image: source page + crop box (on the 1920×1080 page grid)
  build_media.py       regenerates all media from the original files
```

## 6. Replacing or adding images

All images are cut from the 288 ppi page exports of the portfolio (`../288ppi/Artboard N.jpg`).
Each entry in `scripts/media/images.json` is:

```json
"shafaq-01": { "page": 12, "box": [0, 0, 1920, 1080] }
```

`page` is the PDF page number, `box` is `[x0, y0, x1, y1]` on a 1920×1080 grid.

To **replace** an image with a better source (for example a 4K render):
1. Export it as a JPG and put it somewhere next to the repo.
2. Easiest path: crop/resize it yourself to the same aspect ratio, then overwrite `public/media/img/<id>-720|1280|2048.(avif|webp)`.
3. Or update `images.json` and rerun the script:

```bash
python3 scripts/media/build_media.py --only images --ids shafaq-01 --force
# needs Python 3.9+ and Pillow 11.2+ (pip install pillow)
```

Videos: `python3 scripts/media/build_media.py --only video` (needs ffmpeg). Loops, posters and cut points are listed at the top of the script.

## 7. Adding a new project

1. Add its images to `scripts/media/images.json` and run the media script (step 6).
2. Add an entry to `PROJECTS` in `src/data/projects.ts` (title, track, kind, tagline, blocks, chapters with frames, tone colours).
3. Add its slug to `ORDER` (this also sets the "Next recording" sequence).
4. `npm run build`. The page is generated at `/work/<slug>`, appears in the tracklist overlay and in its track index.

## 8. Behaviour notes

- **Reduced motion**: no smooth transitions, parallax, pinning or autoplaying previews. All content stays visible.
- **Touch devices**: no custom cursor or hover previews; titles show their image inline; valU reveals on scroll, Spotify compares by drag.
- **Video**: previews load only when they scroll into view, play muted, pause off-screen. Full films load and play with sound only after a click. Data-saver mode disables previews.
- **Fonts**: Albertus Medium is a commercial Monotype typeface. Confirm that your licence covers web embedding before going live; otherwise replace `public/fonts/albertus-medium.woff2` (one `@font-face` in `src/styles/global.css`).
